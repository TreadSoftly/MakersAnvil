# Makers Anvil Roadmap

## Windows First

1. Clean local app foundation.
2. Durable workspace state.
3. Workspace data directory and safe local settings.
4. Safe runtime file intake.
5. Portable runtime paths and relocation safety.
6. Durable explainability and handoff contract.
7. Metadata-derived route preview.
8. Output bundle and proof panels.
9. Path-redacted tool detection.
10. Semantic tool dry-run planning.
11. Single-route execution gate foundation.
12. Backup, restore, update, and uninstall dry-runs.
13. Windows packaging and clean-machine proof.

## Planned Later

- macOS runtime proof.
- Linux runtime proof.
- Browser-hosted mode with local-only actions redesigned or removed.
- Remote-safe collaboration workflows.
