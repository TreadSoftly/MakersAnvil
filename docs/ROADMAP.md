# Makers Anvil Roadmap

## Windows First

1. Clean local app foundation.
2. Durable workspace state.
3. Workspace data directory and safe local settings.
4. Safe runtime file intake.
5. Portable runtime paths and relocation safety.
6. Durable explainability and handoff contract.
7. Metadata-derived route preview.
8. Output bundle and proof panels.
9. Path-redacted tool detection.
10. Semantic tool dry-run planning.
11. Single-route execution gate foundation.
12. Execution request and audit preview foundation.
13. Contained job workspace and cancellation record foundation.
14. Previous-app design assimilation and source explanation remediation.
15. Preview-first maker workbench shell and responsive dashboard foundation.
16. Complete instructional source and line-by-line learning layer.
17. Previous-app unification and Windows desktop executable foundation.
18. Explicit authorization and portable native/browser intake foundation.
19. Modular previous-app capability, help, event, and settings migration.
20. Single-route contained execution with cancellation, audit, and output proof.
21. Backup, restore, update, uninstall, and repair dry-run lifecycle contracts.
22. Windows installer foundation, upgrade/removal gates, signing path, and clean-machine proof harness.
23. Promote the previous working React application and adapt it to portable current services.
24. Restore safe preview and desktop interaction parity, then split large frontend responsibilities without visual regression.

## Planned Later

- macOS runtime proof.
- Linux runtime proof.
- Browser-hosted mode with local-only actions redesigned or removed.
- Remote-safe collaboration workflows.
